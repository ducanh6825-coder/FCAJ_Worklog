## Weekly achievements

- Explain how browsers call EC2, where the application checks sessions before accessing S3.
- Understand password hashing and distinguish application sessions from AWS permissions supplied by an IAM role.
- Understand HTTPS transport protection and why self-signed certificates require verification and are not automatically trusted.
- Define file type and size restrictions, safe filenames, and access checks for each document operation.
- Combine VPC, EC2, S3, and CloudWatch into an architecture and identify functional requirements for the proposal.
