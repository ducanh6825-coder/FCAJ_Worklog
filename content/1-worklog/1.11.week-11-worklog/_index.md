## Weekly achievements

- Select the correct CPU metric, configure alarm conditions, and assess alarm state history.
- Understand how to verify log delivery from the application through the Agent to a log group and stream.
- Design tests for correct/incorrect login, unauthenticated requests, invalid uploads, and downloaded file integrity.
- Distinguish S3 AccessDenied results from timeouts and connectivity failures instead of treating them as equivalent.
- Record Pass, Fail, or Not tested based on actual outcomes and restore temporary configurations.
