This worklog supports **Design and Deployment of a Secure Web Server on AWS Using VPC, EC2, S3, and CloudWatch**, using a website with login and document uploads/downloads.

Weeks 1–8 focus on foundational learning; weeks 9–12 apply that knowledge to the workshop, testing, and documentation.

**Learning resource:** [AWS Cloud Journey](https://cloudjourney.awsstudygroup.com/). I completed each learning topic on its study day, then consolidated and applied the knowledge to develop the workshop.
